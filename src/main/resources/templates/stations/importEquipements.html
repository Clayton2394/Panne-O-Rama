Importer des équipements

Format attendu

Un fichier CSV encodé en UTF-8, avec ; comme séparateur et une ligne d'en-tête :

reference;description;type;etat
ASC-101;Ascenseur quai 2;ASCENSEUR;FONCTIONNEL
ECR-102;Écran hall nord;ECRAN_INFORMATION;
  • reference et type sont obligatoires, la référence doit être unique.
  • type : ASCENSEUR, ESCALATOR, PORTIQUE, DISTRIBUTEUR ou ECRAN_INFORMATION.
  • etat : FONCTIONNEL ou EN_PANNE (FONCTIONNEL si vide).
  • Si une seule ligne est invalide, aucun équipement n'est importé.
